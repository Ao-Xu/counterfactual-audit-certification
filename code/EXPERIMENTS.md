# Paper-to-code map

This map follows the current manuscript, not the chronology of earlier
internal experiments. “Source included” means the implementing script is in
this repository; it does **not** mean the requisite data, weights, saved
predictions, or original figure assets are included.

| Manuscript evidence | Main code | Reproducibility from this source-only archive |
|---|---|---|
| Main controlled pairing/reuse panel and Appendix controlled factorial | `pairing_analysis/`, `sampled_interventions/`, `shared_anchor/` | Frozen scripts/configurations included; run to generate results. Some later analyses require separately generated stress/retrospective inputs. |
| Main independent-pilot planning and cost panels | `planning/`, `certificate_efficiency/`, `scripts/plots/plot_planner_costs.py` | CPU study and tests can be run from a fresh copy. Generated result tables are not bundled. |
| Main combined evidence figure | `scripts/plots/plot_main_evidence.py` | Requires the planner summary and pairing threshold CSV, generated by the corresponding workflows. |
| Appendix allocation, power, selection and ReCoRD diagnostics | `certificate_efficiency/`, `sampled_interventions/`, `shared_anchor/`, `finite_catalog/`, `identification_audit/` | Code included; ReCoRD model predictions and other finite-catalog inputs are not bundled. |
| MultiNLI/Qwen training-volume motivation and paired-utility checks | `language_models/experiments/llm_cfpt/`, `language_models/experiments/comparative_utility/` | Training/evaluation scripts included; original generation pools, checkpoints, cached judgments and model predictions absent. The paper's original introductory PDF cannot be regenerated from raw curve arrays in this archive. |
| HANS/ANLI and shift-granularity diagnostics | `language_models/experiments/hans_suite/`, `language_models/experiments/shift_granularity/`, `identification_audit/` | Scripts included; obtain public datasets and checkpoints separately. Some plots also require historical saved predictions not in this release. |

## Interpretation boundaries

- Controlled simulations can test an estimand or planning mechanism; they are
  not evidence that a Qwen model satisfies all population assumptions.
- Scripts that analyze saved predictions require the same split and prediction
  artifacts as the paper. Replacing those inputs with a different run yields
  a new experiment, not a numerical reproduction of the published figure.
- `planning/` is the clearest end-to-end workflow in this archive. It fixes
  the menu before fresh final outcomes and retains the infeasible pilots in
  the end-to-end denominator.
- The released ZIP is deliberately source-only. Obtain data and model weights
  from their respective providers under their own terms; do not expect the
  script directory alone to contain them.
