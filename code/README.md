# Reproduction code

This directory contains the public **source-only** companion to the paper.
The names describe the current scientific role of each component; old internal
run-version names have been removed from the directory layout. Numerical
settings and seeds in the frozen configuration files are unchanged. Renaming
package imports required refreshing source-byte locks for `planning`; it did
not rerun the paper's experiments or change their statistical design.

## Quick check

Use Python 3.10 or newer in an isolated environment. The controlled CPU run
was previously verified on Windows with Python 3.10.19, NumPy 1.26.4, SciPy
1.15.3, and Matplotlib 3.10.8. Optional model dependencies are listed
separately; installing them does not supply data or weights.

```powershell
Set-Location code
python -m pip install -r requirements.txt
python -m unittest discover -s planning/tests -v
python -m unittest discover -s scripts/tests -v
```

The tests are code/integrity checks, not independent verification of every
empirical result in the manuscript.

## Reproducing the controlled planner

Run from `code/` in a **fresh copy**. The full design evaluates 144 pilot
plans and the selected fresh audit stages; it is CPU-only but may take several
minutes. The runner refuses to overwrite existing locks/outcomes.

```powershell
python -u -m planning.run pilot
python -u -m planning.run final
python -u -m planning.run benchmark
python -u -m planning.report
```

The protocol, safeguards, expected outputs, and frozen settings are in
[`planning/README.md`](planning/README.md). The result tables generated by
these commands are not included in the archive.

## Plotting and other experiments

After the planner and pairing analyses have produced their tables:

```powershell
python scripts/plots/plot_planner_costs.py
python scripts/plots/plot_main_evidence.py
```

The second command additionally requires
`pairing_analysis/results/dense_thresholds.csv`. Both commands accept input
and output paths via `--help`, and save new figures under `outputs/figures/`.
They do not silently substitute data when an input is missing.

See [`EXPERIMENTS.md`](EXPERIMENTS.md) for the paper-to-code map. The Qwen,
MultiNLI, HANS, ANLI, and ReCoRD workflows require separate datasets, model
checkpoints, or saved predictions. Their scripts are provided for inspection
and adaptation, but this release cannot recreate all language-model plots
from source alone.

## Package layout and safeguards

- `planning/`, `pairing_analysis/`: main controlled evidence.
- `certificate_efficiency/`, `sampled_interventions/`, `shared_anchor/`:
  supporting certificate and resource-allocation experiments.
- `finite_catalog/`, `identification_audit/`: finite-catalog audit code.
- `language_models/experiments/`: text/model experiments.
- `scripts/`: exports, interval checks, plotting, and ZIP builder.
- `requirements*.txt`: controlled, optional model, and optional figure
  dependencies.

Frozen protocols retain local configuration locks, including small checksum
sidecars where the runnable code checks them. Redundant historical delivery
manifests, byte inventories, superseded figure-repair copies, and archives are
not part of this release. `python scripts/build_archive.py` rebuilds the
source-only ZIP; it excludes generated results, model data, caches, and Git
history.
