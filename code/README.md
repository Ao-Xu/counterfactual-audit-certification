# Code for “When Can Counterfactual Audits Certify a Fine-Tuning Gain?”

This is the **public source-only release** accompanying the manuscript. The
repository's `code.zip` contains the same `code/` tree. It includes experiment
and plotting scripts, frozen configuration manifests, tests, and a per-file
SHA-256 inventory. It does **not** contain model weights, licensed datasets,
raw predictions, historical result tables, or the paper's figure PDFs. Do not
interpret this archive alone as a full numerical reproduction package.

## Contents

- `oral_planner_v6/`: frozen pilot-plan-certify controlled experiment, tests,
  and an executable protocol (`oral_planner_v6/README.md`).
- `oral_attribution_v5/`, `oral_shared_v4/`, `oral_sampled_v3/`,
  `oral_efficiency_v2/`: related controlled simulations and analyses.
- `identification_audit_v1/` and `oral_upgrade/`: finite-catalog audit and
  follow-up analysis code.
- `overleaf/experiments/`: manuscript-related Qwen/MultiNLI, HANS/ANLI,
  comparative-utility, and shift-granularity scripts.
- `tools/`: figure/data postprocessing, integrity checks, and package builder.
- `CODE_INDEX.json`: allowlist used to build the source archive.
- `DATA_HANDOFF.md`: inventory of the **historical full evidence bundle**, not
  a list of inputs present in this source-only release.

Several historical scripts require external datasets, model checkpoints, or
saved experiment outputs. Their presence here does not mean those dependencies
are supplied or that training was rerun for this public release. In particular,
the paper's generated-text plots cannot all be recreated from `code.zip` alone.

## Environment and quick checks

Use Python 3.10 or newer in an isolated environment. The controlled CPU run
was verified with Python 3.10.19, NumPy 1.26.4, SciPy 1.15.3, and Matplotlib
3.10.8 on Windows. `requirements.txt` records the controlled-run dependencies;
`requirements-model.txt` and `requirements-figures.txt` cover optional model
and plotting code, respectively. These are observed environments, not a
cross-platform guarantee for every historical script.

From the repository root:

```powershell
Set-Location ./code
python -m pip install -r requirements.txt
python -m unittest discover -s oral_planner_v6/tests -v
python -m unittest discover -s tools/tests -v
```

To run the frozen controlled planner in a fresh working copy, follow
`oral_planner_v6/README.md`. It writes its own `results/` directory and refuses
to overwrite existing locks/outcomes. Do not alter its frozen manifest and
then describe the output as a reproduction of the paper's locked protocol.

For HANS, set `CFPT_ROBERTA` to an available local RoBERTa checkpoint or make
`roberta-base` available in the local Hugging Face cache. The model runner uses
`local_files_only=True` and does not download weights.

## Provenance and scope

`RECOVERED_SOURCES.json` records hashes for a subset of archived scripts, and
the individual frozen manifests lock the corresponding controlled experiments.
The public-release changes are limited to replacing a machine-specific example
in `oral_planner_v6/README.md`, replacing a machine-specific default model
path in the HANS runner with `roberta-base`, and clarifying this source-only
scope. The original experiment outcomes were not regenerated by these edits.
`DELIVERY_SHA256.json` inside the ZIP hashes the published file bytes.
